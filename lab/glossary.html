Glossary

Plain-language definitions of the terms this lab uses, in the order you meet them. Words in the modules that are underlined with dots link here.

The decomposition

Percentage point (pp)
The unit for a difference between two percentages. If 16% of one group and 6% of another have a diagnosis, the gap is 10 percentage points. It is not “10%”, which would suggest a relative change.
Gap
The difference in the average outcome between two groups. Here it is the share of children with a reported ADHD diagnosis in English-language households minus the share in other-language households.
Twofold Oaxaca–Blinder decomposition
A way of splitting a gap into two parts using a regression fitted in each group. One part is due to the groups having different average characteristics; the other is what remains (Blinder, 1973; Oaxaca, 1973).
Explained part
How much smaller the gap would be if the second group had the first group's average measured characteristics, holding the regression coefficients fixed. “Explained” means accounted for by composition. It is accounting, not a cause.
Unexplained part
The rest of the gap: the part linked to differences in the regression coefficients, which includes anything not measured. It can be negative.
Reference coefficients
The set of regression coefficients used to value differences in characteristics. This lab uses the English-language group's coefficients. Using the other group's, or a pooled set, changes the split (Module 2's switcher).
Linear probability model (LPM)
An ordinary linear regression with a 0/1 outcome. Its coefficients are changes in probability, so its decomposition adds up exactly. Some fitted values can fall outside 0–1.
Logit model
A regression for a 0/1 outcome that keeps predicted probabilities between 0 and 1. Because it is not linear, a decomposition plugged in at the group means does not add up to the gap.
Fairlie decomposition
A decomposition for logit models that averages predicted probabilities over children instead of plugging in means, so the parts add up (Fairlie, 2005). Its block-by-block split depends on the order in which blocks are switched.
DFL reweighting
A decomposition that reweights one group so that its covariate mix looks like the other group's, then compares the averages (DiNardo, Fortin & Lemieux, 1996). No outcome regression is needed.
Effective sample size
After reweighting, how many equally weighted children the data are worth. If a few children carry very large weights, the effective sample size is small and the estimate is unstable.

Survey design

Survey weight
How many children in the population each sampled child represents. Weighted estimates describe the population, not just the sample.
Stratum (plural strata)
A group the sample was drawn from separately, such as a state. Sampling within strata makes estimates more precise, and variance formulas must know the strata.
Primary sampling unit (PSU)
The unit sampled first, here the household. Children in the same PSU can be alike, so the variance is computed from differences between PSUs. In this file each household has one sampled child.
Design degrees of freedom
For a stratified design: number of PSUs minus number of strata. It sets how much the variance estimate itself can be trusted.
Domain estimation
Estimating for a subgroup (a “domain”, such as other-language children) while keeping the whole sample in the variance calculation. Children outside the domain count as zeros. Deleting them first, then declaring the design, gives the wrong variance (Module 3, Case C).
Lonely (singleton) PSU
A stratum left with only one PSU, usually after wrongly subsetting the file. Variance cannot be computed from one PSU, so software must drop the stratum or apply an arbitrary adjustment.
Taylor linearization
The standard way to compute variances for survey estimates. It approximates a complex estimate by a weighted sum and applies the design's variance formula to that sum.
Influence values (influence function)
Each child's contribution to an estimate: how much the estimate would move because of that child. Summing them within PSUs and comparing PSUs gives the Taylor variance.
Bootstrap (Rao–Wu)
Estimating uncertainty by recomputing the result many times on resampled data. For surveys, whole PSUs are resampled within strata, and the Rao–Wu method rescales the weights so the variance is not understated (Rao & Wu, 1988).
95% confidence interval
A range computed so that, over repeated samples, 95% of such ranges would contain the true value. A wide interval means the data are imprecise about that number.

Missing data and checks

Complete cases
The children with every variable in the model observed. A regression can only use these, so its sample is smaller than the sample for a simple rate.
Multiple imputation; implicates
Census filled in missing family income several times with plausible values. Each filled-in version is an “implicate”; this file has six (FPL_I1 to FPL_I6). Analysing all six shows how much the guesses matter.
Rubin's rules
How to combine results across implicates: average the six estimates, and add the spread between them to the average variance, so the interval includes the uncertainty about the missing income (Rubin, 1987).
Skip pattern; structural zero
A question is skipped because an earlier answer makes it irrelevant. For example, if a child saw no doctor, the question about preventive visits is skipped, and the true answer is zero visits. Treating that skip as missing drops exactly the children with no visits (Module 4, Trap 1).
Falsification check
A deliberate test that should change the result if your code is right (or leave it unchanged when it should). If it doesn't move as expected, something is wrong.
Sensitivity analysis
Re-running the analysis with a different reasonable choice to see whether the conclusion holds.
E-value
The minimum strength of association, on the risk-ratio scale, that an unmeasured confounder would need with both the exposure and the outcome to fully explain away an observed association (VanderWeele & Ding, 2017). It does not show that no such confounder exists.
