Module 2. The machine

Twofold Oaxaca–Blinder on the linear probability model, one piece per screen, always with the study's own numbers.

Piece 1: two group means

The outcome y is 1 if the caregiver reports an ADHD diagnosis, else 0. Its weighted mean in each group is a rate. On the complete cases: English %, other-language %.

Every rate and covariate mean in this module is computed on these complete cases, so it differs a little from the all-children figures in Modules 1 and 4 (for example, the share insured or with a preventive visit).

Gap = ȳE − ȳO = pp. Everything that follows splits this number; nothing changes it.

Piece 2: one regression per group

Fit the same linear probability model (LPM) separately in each group: y = x′b + error, with the same columns x (intercept, demographics, attention items, behaviours, access). A coefficient is the change in the probability of reported diagnosis per unit of that covariate, within that group.

Because each model has an intercept, it passes exactly through its group's means: ȳE = x̄E′bE and ȳO = x̄O′bO. That one fact makes the decomposition add up exactly.

Piece 3: the counterfactual

Add and subtract x̄O′bE, the rate the other-language group would have with its own covariates but the English slopes:

Gap = (x̄E − x̄O)′bE  +  x̄O′(bE − bO)

The first term is explained (differences in covariate means, weighted by English slopes). The second is unexplained (differences in slopes and intercepts). Each explained term belongs to one covariate, so you can add terms up into blocks.

Compositional, not causal. “Explained” is the part of the gap that lines up with differences in measured covariates.

Interaction 3: logit versus linear probability model

Same children, same covariates (a reduced set, so that both group logits converge with only diagnoses among the other-language children in the full specification). Each method splits the gap into explained and unexplained.

Predict first: if you plug group means into a logit model, will explained + unexplained equal the observed gap?

Compositional, not causal, on any scale.

Why predict first: committing to an answer before seeing the result, then getting feedback, can improve later learning (Kornell, Hays & Bjork, 2009, with verbal materials; using it here is an extrapolation).
