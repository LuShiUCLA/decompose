Module 4. The two traps

Two coding decisions quietly change the study's numbers. You will find both in the codebook yourself. The lab will not point at them until you have looked.

Falsification sandbox: insurance

What each falsification check proves

  • Re-run with the skips dropped. The other-language preventive-visit rate jumps from % to %. If your program shows no change, it is not reading S4Q01.
  • Re-run with CURRCOV. The insured rate moves (English % → %) and children change status. If nothing moves, your program is not reading the variable you think it is.
  • Re-run on a pre-subset file. Singleton strata appear and the design df falls (Module 3).

A check that cannot fail proves nothing. Each of these is built so that a specific coding error would make it fail.

Compositional, not causal. Correct coding makes the description accurate; it does not make it causal.
